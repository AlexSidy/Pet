# Настройка HTTPS для Angular Dev Server

## Обзор

Приложение настроено для работы с HTTPS в режиме разработки. Это необходимо для интеграции с VK ID SDK, который требует HTTPS для `redirectUrl`.

## Автоматическая генерация сертификатов в Docker

При запуске контейнера через `docker-compose`, SSL сертификаты генерируются автоматически при первом запуске через entrypoint скрипт (`docker-entrypoint.sh`).

### Запуск с Docker Compose

```bash
docker-compose up -d --build
```

Сертификаты будут созданы автоматически в контейнере в каталоге `/app/ssl/`.

## Локальная разработка (без Docker)

Для локальной разработки на вашей машине:

### Windows (PowerShell)

```powershell
.\generate-ssl-cert.ps1
```

### Linux/macOS (Bash)

```bash
chmod +x generate-ssl-cert.sh
./generate-ssl-cert.sh
```

### Запуск с HTTPS

```bash
npm run start:https
```

Или:

```bash
npm run serve:https
```

Приложение будет доступно по адресу: `https://localhost:4200`

## Важные замечания

1. **Самоподписанные сертификаты**: Используются самоподписанные сертификаты для разработки. Браузер покажет предупреждение о безопасности - это нормально для локальной разработки.

2. **Доверие к сертификату**: При первом запуске браузер может показать предупреждение. Нужно нажать "Продолжить" или "Advanced" -> "Proceed to localhost".

3. **VK ID настройки**: В настройках VK приложения (ID: 54294867) должен быть зарегистрирован `redirectUrl`:
   - Для локальной разработки: `https://localhost:4200` или `https://localhost:4200/auth`
   - Для продакшена: ваш реальный домен с HTTPS

4. **Git**: Каталог `ssl/` и файлы сертификатов исключены из Git через `.gitignore`.

## Структура файлов

```
ScanPerson.UI/
├── ssl/                    # SSL сертификаты (генерируются автоматически)
│   ├── server.key         # Приватный ключ
│   └── server.crt         # Сертификат
├── docker-entrypoint.sh   # Скрипт для генерации сертификатов в Docker
├── generate-ssl-cert.ps1  # Скрипт для Windows
├── generate-ssl-cert.sh   # Скрипт для Linux/macOS
└── angular.json           # Конфигурация Angular с HTTPS
```

## Устранение проблем

### Ошибка: "ENOENT: no such file or directory, open 'ssl/server.crt'"

**Решение**: Убедитесь, что:
1. Entrypoint скрипт выполняется (проверьте логи контейнера)
2. OpenSSL установлен в контейнере
3. Каталог `ssl` исключен из volume mount в `docker-compose.yml`

### Браузер не доверяет сертификату

**Решение**: Это нормально для самоподписанных сертификатов. Нажмите "Продолжить" или добавьте исключение в браузере.

### VK ID не работает

**Решение**: 
1. Убедитесь, что приложение работает по HTTPS
2. Проверьте, что `redirectUrl` в настройках VK приложения точно совпадает с URL вашего приложения
3. Проверьте консоль браузера на наличие ошибок CORS
